5 odstępstw, posortowane od krytycznych

Visual · Logo rules
Logo Geers użyte w nieautoryzowanym kolorze (#FF4B00 zamiast lead green #006B3F)
Fix: Zamień na oficjalny wariant lead green. Inne kolory marki są dopuszczone tylko jako accent, nigdy jako kolor samego logo.
Visual
Język · Lexicon AudioCare
Użyto słowa "gadżet" w kontekście aparatu słuchowego (2 wystąpienia)
Fix: Zastąp "gadżet" → "sprzęt medyczny" lub "rozwiązanie audiologiczne". Patrz: hub → Język → Słowa zakazane.
Język
Visual · Fotografia
Zdjęcie wygląda na stock — model trzyma aparat w wystudiowanej pozie
Fix: Zero stocku — zasada #1. Użyj materiałów z Geers photo library (real-life, unstaged). Patrz: hub → Visual → Fotografia, 3 zasady.
Visual
Visual · Kształty
Kompozycja używa 5 oficjalnych kształtów — przekroczono limit max 3 na layout
Fix: Zredukuj do 3 kształtów. Zachowaj rotację — kształty zawsze rotowane, nigdy statyczne. Patrz: hub → Visual → 3 oficjalne kształty.
Visual
Strategia + voice · Tone
Tryb tonu "Casual" zastosowany na komunikacie B2B — zaproponuj "Ekspert"
Fix: Dla komunikacji do protetyków i partnerów medycznych użyj trybu Ekspert (najwyższa specjalistyczność, najmniej kolokwialny). Patrz: hub → Strategia + voice → 3 tryby tonu.
