Hard rules - non-negotiable
  • No long dashes, ever. Not em, not en - every dash in r352 copy is "-", usually spaced " - ". Applies to EN and PL alike.
  • Dark theme is primary and default. Light theme is an override layer (body.global-light-mode in src/styles/theme.css), never a parallel design.
  • Silence = stillness. Nothing pulses when the music is off; all beat-locked motion is gated by u_live.
  • Never fabricate metrics. Every published number must be verifiable; unverified claims get downgraded or flagged, never shipped optimistic.
  • Never rewrite client quotes. Testimonials ship verbatim with real name + role + company, or carry a placeholder warning comment.
  • PL + EN parity. All copy is bilingual at birth; EN is the structural source of truth and fallback, so EN must always exist.
  • prefers-reduced-motion respected in every canvas - one still frame, no rAF loop.

Theming architecture

Mechanics

  • Dark default: ThemeProvider starts 'dark'; .dark class on the app root div, not <html>; dark: variants via @custom-variant dark (&:is(.dark *)).
  • Light mode = two mechanisms: .dark removed AND body.global-light-mode added - token swap plus ~90 !important override rules on escaped Tailwind classes.
  • Toggle choreography: body.theme-transitioning puts 0.8s cubic-bezier(0.22,1,0.36,1) on bg/color/border/fill/shadow; two-layer sweep lime bg-[#D4FF00]/90 then target #0A0A0A/90 or #F1F6FA/90, ease [0.76,0,0.24,1], R352Symbol in #D4FF00, tagline clipPath reveal.
  • Header: mix-blend-difference until scrolled; light mode kills the blend, forces black text; .mix-blend-screen elements get opacity 0 in light.

Known pitfall: the override list is an allowlist

Only literally enumerated class names flip in light mode; any new hardcoded color silently stays dark-styled on the light background.

Use semantic tokens, the dual-variant pattern (text-[#9abb00] dark:text-[#D4FF00], bg-white dark:bg-[#0a0a0a]), or add the class to theme.css.

Rules

  • Default to semantic tokens (bg-background, text-foreground, bg-card, border-border) - the only colors guaranteed to flip in light mode.
  • One accent at a time: lime #D4FF00 is the signal; clay #D97757 only for AI-flavored accents, never competing with lime in one element. #DAFF45 is logo artwork only.
  • Lime on light backgrounds uses the derivative greens (#6B8F00 default, #9ABB00 dual-variant) or flips to black.
  • Every new hardcoded color is paired: x dark:y variants or a theme.css light-mode override entry - otherwise it reads as a dark-mode leak.
  • In GLSL: lime vec3(0.831,1.0,0.0), clay vec3(0.851,0.463,0.341) - keep the literals so all canvases match.
  • Focus is global (2px lime ring, offset 3px; black in light) - no per-component focus colors or outline-none.
  • Surface layering (dark): base #151515 -> cards #0a0a0a (hover #0f0f0f) -> deepest #050505/#080808 -> graphite lift #363636; hairlines border-white/5 or /10.
  • Don't rely on decorative bg-gradient-to-b/r surviving light mode; feather band edges instead of hard borders.

Typography

A two-voice system: Tanker (display, single weight 400, all-caps machine-label voice) against a quiet mid-weight grotesque body capped at 500 - contrast comes from size, case and lime, not weight.

Display voice

Tanker

--font-display: "Tanker", sans-serif (theme.css:69). Safari stack: "Tanker", "Plus Jakarta Sans", system-ui, sans-serif (theme.css:353).

Text over canvases

Soft black glow only

  • Tanker = labels, kickers, numerals, uppercase display moments; one weight (400), never fake-bold it, never load new weights.
  • Big headings are the body sans, not Tanker: font-bold tracking-tighter + stepped scale or clamp; expect rendered weight 500 (don't expect bold/semibold/black to differ).

  • Hero leading tightens with size: 0.95 desktop, 0.85 token, 0.76 mobile; body stays relaxed.
  • .font-mono is a voice, not a face - if true code styling is ever needed, add a real mono font first.
